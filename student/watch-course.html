2.1 Semantic HTML Basics

Module 2: HTML5 & CSS3 • Published March 12, 2026

In this lecture, we explore the power of Semantic HTML and why it's the backbone of professional web development. We'll dive into how tags like <main>, <article>, and <section> provide context to both the browser and search engines.

By the end of this session, you will understand the difference between structural tags and presentational tags, and how to structure a modern webpage following best practices for SEO and accessibility.

Lecture Objectives:
  • Understand the core concept of Semantic HTML.
  • Identify and correctly use landmark elements.
  • Improve accessibility with meaningful document structure.
  • Learn how search engines interpret semantic data.
